# Código de Conduta

Todos os participantes deste projeto devem seguir regras básicas de convivência:

- Seja respeitoso e cortês com os demais.
- Não publique conteúdo ofensivo, discriminatório ou de assédio.
- Seja receptivo ao feedback e contribuições de outras pessoas.
- Reporte má-conduta abrindo uma Issue ou contatando os mantenedores.

Este repositório segue um código de conduta simples para manter a comunidade segura e acolhedora. Mantenedores reservam-se ao direito de remover conteúdo e bloquear usuários que violem estas regras.
